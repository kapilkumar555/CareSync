# CareSync Backend 🚑

CareSync is a healthcare management backend system built using Node.js, Express, and MongoDB.  
It provides APIs for managing users, appointments, and healthcare records.

---

## 🚀 Live Server
🔗 https://caresync-backend-veb7.onrender.com

---

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Render (Deployment)
