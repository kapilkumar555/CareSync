# 📌 Overview

CareSync is a modern healthcare management platform designed to simplify patient and healthcare service management.
The application provides secure authentication, appointment handling, responsive UI, and seamless backend integration.

This project demonstrates full-stack development skills including:

* Frontend Development
* Backend API Development
* Database Integration
* Authentication
* Deployment & Production Hosting

# 🔧 Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/kapilkumar555/CareSync.git
cd CareSync
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 3️⃣ Frontend Setup

```bash
cd clientside
npm install
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file inside backend folder:

```env
PORT=10000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
